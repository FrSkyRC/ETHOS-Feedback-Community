## Introduction

Config script for FrSky ESC.

## Fixes

- Fix the display and setting issue in some fields.
- Fix an issue in Ethos 1.6.2 that could cause a read failure.

## V1.1.6

- Fixed an issue where device could not be configured when telemetry data was received from an external module.

## V1.1.7

- Added the support to configure the device through the S.Port connector
- Fixed the number edit default step error

If you are running Ethos 1.6.0 or later, you can find it in the Device Config menu.
